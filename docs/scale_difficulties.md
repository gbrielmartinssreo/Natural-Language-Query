1. CSV limpo
   - uma tabela
   - cabeçalhos claros
   - sem fórmulas
   - tipos consistentes
2. XLSX simples
   - uma ou mais abas
   - tabelas relacionadas
   - datas, moedas, percentuais
   - algumas fórmulas
3. XLSX semi-estruturado
   - título antes do cabeçalho
   - linhas de totais
   - células vazias
   - subtabelas
   - múltiplos blocos na mesma aba
4. Planilha corporativa infernal
   - células mescladas
   - cabeçalhos multinível
   - cores com significado
   - fórmulas
   - abas auxiliares ocultas
   - gráficos
   - pivôs
   - observações no meio da tabela
